# Cppcheck 静态检查

## 目的

使用 Cppcheck 对 C 代码进行静态分析，发现常见的缺陷、可移植性问题和可维护性问题。

## 使用原则

- 检查范围由当前项目决定，不在本规则中固定源码目录或排除目录。
- 编译选项、头文件路径、预处理宏和 C 标准由项目构建配置提供。
- 检查结果先报告给用户；修复代码前必须获得用户确认。

## 基础检查

执行检查时，启用警告、风格、性能和可移植性类别；将不确定结果一并报告，并以非零退出状态表示发现的问题。

```bash
cppcheck --enable=warning,style,performance,portability --inconclusive --error-exitcode=1 <检查目标>
```

## 检查结果

- 将问题按文件、位置和严重程度汇总。
- 区分确认问题与不确定结果。
- 无法判断的问题先询问用户，不自行压制或忽略。
