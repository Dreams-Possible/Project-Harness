# agent-read 技能说明

## 使用场景

需要完整加载当前目录中的通用配置、规则和技能定义时使用。

## 技能定位

本技能是手动执行的上下文加载工具，从当前配置根目录递归发现并读取需要的通用文件。

## 读取范围

- 从当前配置根目录开始递归扫描文件。
- 跳过二进制文件、构建产物和临时文件。
- 将发现的文本配置、规则文件和技能定义按相对路径字母序读取。
- 默认内容和已启用扩展均按实际目录结构发现，不维护固定清单。
- 只读取通用配置，不推断或读取用户工程中的项目上下文。

## 执行流程

1. 向用户说明将读取当前目录中的通用配置。
2. 递归扫描并列出符合读取范围的文件。
3. 按相对路径字母序读取发现的文件。
4. 若文件不存在或无法读取，记录原因但不中断其他文件的读取。
5. 输出摘要：已读取文件、跳过的目录，以及未读取文件及原因。

## 注意事项

- 本技能只读取文件，不进行写入。
- 不维护固定文件清单；目录新增、删除或重组后，下一次执行会自动适配。
- 读取结果仅代表本次执行实际读取到的内容，不代表用户工程的全部上下文。
